# gapul Writing Voice — 本人の日本語文体で書く

gapul本人が書いたと自然に読める日本語散文を生成・推敲するためのスキル。2026-07-30に本人がサンプルを2回添削して確定した文体ルールを収録する。汎用の「AIっぽさ除去」は [humanizer-ja] が担うが、本スキルは**gapul固有の声**に寄せる点が異なる。

## 適用範囲

- 2つのモードがあり、文脈で切り替える。混同しない。
  - 散文モード（既定）: レポート/課題の記述式解答、振り返り、議事メモ、提出文書、ブログ的散文。この節以降の「コア原則」〜「ワークフロー」が該当。
  - 数学証明モード: 数学・情報科学の証明や、証明を含む解答。末尾の「数学証明モード」節に従い、散文モードのルール（一人称・低ヘッジ等）は持ち込まない。
- 使わない: 学習資料（具体例必須の別方針）、コード/コメント、箇条書きだけのメモ。
- トリガー語: 「自分の文体で」「私っぽく」「人間らしく」「自然な文体に」「素の文体で」。

## コア原則（最優先・順守）

1. **言い切り。** だ・である調で断定する。「〜である」「〜だ」で終える。
2. **結論先出し。** 要点・結論を段落や文章の冒頭に置く。締めに回さない。
3. **低ヘッジ。** 逃げの表現を入れない。下記「禁止リスト」を機械的に削る。
4. **畳んで書く。** 逆接は「〜が」で一文内につなぎ、細切れにしない。読点を多用しない。

## 禁止リスト（見つけたら削除/言い換え）

- フィラー: 「正直」「たぶん」「なんというか」「やっぱり」、強調の単独「もちろん」。
- 推量・態度のヘッジ: 「〜と思う」「〜と考えている」「〜な気がする」「〜だろう」「〜かもしれない」「〜という印象」。
- 口語ぼかし: 文末の「〜な(のだ抜き)」「〜みたいに」「〜って」「〜けど/〜けれど」。
  → 逆接は「〜が」に統一。

## 語彙・言い回しの置換

| ぼやけた語 | 本人の語 |
|---|---|
| でも | しかし |
| だんだん | 次第に |
| 〜もそうで | 〜も同様で |
| 合っている | 性に合っている |
| 気づく | 気付く |
| （技術語）カスタマイズ等 | カタカナで（カスタム 等） |

- 主語は「自分」。「私」より「自分」を好む。
- 口語の引用（「『動けばいい』くらいの気持ち」）は説明文に（「動けば十分と考えていた」）。

## 専門色（機械学習・画像認識）

- 「残すが控えめに」。具体例は1つに絞る（例: 敵対的サンプル、CNN、attention、顕著性マップ、説明可能性）。列挙で盛らない。

## 見本（本人の実文体）

> 作ることと学ぶことは、本来切り離せないものである。新しい技術は本を読むより先に手を動かしたほうが早く身につく。最初から完璧な理解をしようとすると、かえって何も進まない。自分の場合、動くものを作り、動かしながら足りない知識を埋めていくほうが性に合っている。もちろん後から理屈を確認するのは欠かせないが、順序が逆になると知識だけ増えて何も作れずに終わってしまう。

## ワークフロー

1. 下書きを書く（内容重視）。
2. 禁止リストを機械的に削る → 残った文末をだ・である調に。
3. 各段落の結論文を先頭へ移動。
4. 逆接「〜が」で畳む。読点を間引く。専門例が2つ以上なら1つに絞る。
5. 見本と声が合っているか照合。

## 数学証明モード（散文モードとは別レジスタ）

数学・情報科学の証明は、散文モードの声（一人称・低ヘッジ・「〜が」で畳む等）を持ち込まず、標準的な数学の言葉で言い切る。2026-07-30に本人がサンプルを添削して確定。

- 最優先はシンプルさ。満点に必要な本筋だけを最小限で書く。補足・言い換え・余談（蛇足）を足さない。
- 場合分けは `### (i) … のとき` / `### (ii) … のとき` の小見出しで区切る。
- 条件・数式は LaTeX インラインで書く（`$n \le 3$`）。数学記号を地の文に生書きしない。数式で書く方が自然な箇所は言葉で言い換えず数式で書く（合同式 `$\pmod 2$`、`$\equiv$`、`$\sum$`、量化子 `$\forall/\exists$` 等）。ただし不自然なら無理に記号化しない。
- 語彙・語尾は標準寄り: 「高々」（せいぜい×）、「〜とおく」、「〜ので」、断定は「〜である／〜だ」。証明では断定を避けない。
- 前置き・メタ発言・お節介説明を削る（「思い浮かべると見やすい」「あとは〜すればいい」等）。
- 砕けた愛称・言い換え（例: two ears を「耳」）や括弧書きの補足（例:「奇数（$\equiv 1$）」の $(\equiv 1)$）は入れない。標準的な事実はいちいち証明せず言い切ってよい。
- 締めは `∎` を使わず「以上より、〜であることが示された。」で終える。
- 箇条書きは実用として適宜使ってよい。各ケース内は文でつなぐ。太字は使わない。
- 詳細は `math-proof-answer-style.md`。
