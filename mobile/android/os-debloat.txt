# 現在のユーザーから外すプリインアプリ。os.sh がまず
#   adb shell pm uninstall -k --user 0 <pkg>
# を試し、断られたら
#   adb shell pm disable-user --user 0 <pkg>
#   adb shell pm uninstall-system-updates <pkg>
# で無効化して、Play ストアが入れた更新分を消す。純正の Android 17 は root なしだと
# システムアプリの user 0 からのアンインストールを断る ("only root can delete system app
# for a particular user") ので、このスマホでは全部が無効化になる。どちらもシステムパーティションは
# 触らないので、無効化は設定のアプリ画面か `pm enable`、アンインストールは
# `cmd package install-existing <pkg>` でいつでも戻せる。
#
# 候補の探し方:
#   adb shell pm list packages -s | sed 's/^package://' | sort   # プリイン一覧
#   adb shell pm list packages -d                                # すでに無効なもの
#
# 消していいか怪しいものは消さない。ダイヤラ / IMS / carrier 系を外すと
# 電話が着信しなくなる類の壊れ方をする。ほかに残すもの:
#   Pixel ランチャー (com.google.android.apps.nexuslauncher): アプリ切り替えの画面を持つ
#   初期設定ウィザード: プライベートスペースを作るときに使う
#   Play ストア / Play 開発者サービス: ウォレットとおサイフケータイが依存する
#   電話: SIM が無くても緊急通報に要る
#   メッセージ、緊急情報サービス、Android Auto、Digital Wellbeing: 置き換えると機能が減るので残す
